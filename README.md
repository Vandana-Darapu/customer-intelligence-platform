# AI-Powered Data & Customer Intelligence Platform
An end-to-end data project that turns Amazon product reviews into business insights: ratings, product performance, sentiment trends and common customer complaints.
**Status: work in progress.** Currently in Phase 0 (environment setup).
## Planned architecture
Amazon Reviews 2023 -> Python + PySpark (ingest, clean, join) -> MySQL (star schema) -> Pandas/NumPy analysis, scikit-learn sentiment model, complaint mining -> Power BI dashboards and an AI analyst (RAG) -> Streamlit app
## Tech stack
Python, PySpark, SQL, MySQL, Pandas, NumPy, scikit-learn, Power BI, LLM + RAG, Streamlit
## Dataset
Amazon Reviews 2023, McAuley Lab, UC San Diego. This project will use a small number of product categories chosen to fit a laptop. Real row counts will be added here after processing.
